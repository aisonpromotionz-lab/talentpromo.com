AISON PROMOTIONZ WEBSITE

FILES
- index.html: complete responsive website
- assets/aison-promotionz-poster.jpg: supplied poster used on the home page

HOW TO OPEN
1. Extract the ZIP file.
2. Open the aison_promotionz_website folder.
3. Double-click index.html. It opens in Chrome or another browser.
4. For publishing, upload the entire folder (including assets) to a static website host.

FEATURES
- Responsive home page and all seven services from the supplied poster.
- Click-to-call and WhatsApp contact links for +256 771 271886.
- Client enquiry form that prepares a WhatsApp message for the administrator.
- Admin workspace for manually recording follow-up notes in the current browser.

IMPORTANT LIMITATIONS
- The enquiry form opens WhatsApp. The client must press Send in WhatsApp.
- Admin notes are stored only in the browser/device being used. They do not sync to the administrator or other clients.
- The admin access code (2468) is a demonstration only, not secure authentication. Change ADMIN_CODE in index.html, but do not rely on this for protecting sensitive data.
- For genuine shared client accounts, online message storage, secure administrator login and multi-device access, connect a backend/database service before using it for business operations.
